# Regulatory assessment — Method guidance

**Method:** `regulatory-assessment@1`
**Purpose:** Assess stated facts against identified regulatory requirements.
**Required inputs:** applicable requirements; facts; jurisdiction
**Expected outputs:** assessment; evidence; limitations

Apply every section below to the assessment before reporting the work done — an assessment that
omits an applicable requirement or a required sign-off is not complete, however well the rest of
it is written.

## Requirement coverage

Before finalizing the assessment, identify every applicable regulatory requirement for the
stated jurisdiction and confirm the assessment addresses each one individually, rather than a
single blended conclusion. State explicitly which requirement each finding maps to.

## Source currency

For every regulatory source you cite, check that it is the current effective version for the
stated jurisdiction and date, not a superseded version that has since been amended or repealed.
State the version or effective date of each regulatory source you rely on.

## Professional sign-off when required

For every jurisdiction and requirement in scope, identify whether it mandates sign-off by a
licensed or credentialed professional, and state clearly when the assessment must be reviewed or
approved by such a professional before it is relied upon. Never present an unlicensed assessment
as a substitute for required professional sign-off.
